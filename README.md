# n8n Appointment Booking Agent

AI-powered voice appointment booking system built with n8n, ElevenLabs, Twilio, and Google Calendar.

## Features

- AI voice assistant using ElevenLabs
- Phone call handling with Twilio
- Real-time appointment availability checking
- Automatic Google Calendar booking
- Customer booking confirmation

## Workflow Files

- ai_agent.json
- booking.json

## How to Use

1. Import ai_agent.json into n8n.
2. Import booking.json into n8n.
3. Configure Google Calendar credentials.
4. Configure Twilio phone number.
5. Configure ElevenLabs agent.
6. Activate both workflows.
